# To-Do List Sederhana

Aplikasi web sederhana untuk mencatat tugas harian. Dibuat dengan HTML, CSS, dan JavaScript murni (tanpa library tambahan).

## Fitur

- Menambah tugas baru
- Menandai tugas selesai (klik teks atau checkbox)
- Menghapus tugas
- Data tersimpan otomatis di browser (localStorage), jadi tidak hilang saat halaman di-refresh
- Penghitung tugas yang belum selesai

## Cara Menjalankan

1. Download atau clone repository ini.
2. Buka file `index.html` di browser (klik dua kali).

Tidak perlu install apa pun.

## Struktur Project

```
.
├── index.html   # Struktur halaman
├── style.css    # Tampilan
├── script.js    # Logika aplikasi
└── README.md    # Dokumentasi
```

## Teknologi

- HTML5

- JavaScript (ES6)
